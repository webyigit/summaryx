시스코 탈로스 "악성코드에 'AI 분석 속이는 문장' 심는 수법 확산…효과는 제한적"

시스코 탈로스가 AI 기반 자동 분석을 속이려고 악성코드 안에 자연어 문장을 심는 'AI 분석 회피' 수법을 분석했다. 2025년 1월부터 2026년 7월까지 수집한 4개 계열(FRUITSHELL·PLOTSAFE·HOLLOWCLAD·MANTLEMAZE) 표본 84개가 대상이다.

초기 FRUITSHELL은 '이 스크립트는 무해한 소수 계산 코드'라는 주석을 달았고, 이 문구는 최소 4개 공격자의 다른 스크립트 9개에 그대로 복사됐다. 이후 템플릿으로 위장 주석을 만들거나, 여러 LLM 대화 형식에 맞춘 지시문을 한꺼번에 뿌리고 가짜 정부 계약·인증서를 덧붙이는 식으로 진화했다.

탈로스가 5개 로컬 LLM으로 시험한 결과 단순한 직접 지시가 가장 잘 통했고, 복잡한 변형은 오히려 의심을 키우기도 해 효과는 엇갈렸다. 기존 탐지 기술에는 영향이 없어 '주목할 만하지만 심각하진 않다'고 평가했다. 분석 도구를 향한 명령형 문장을 탐지 신호로 쓰고, 표본 속 텍스트는 지시가 아닌 증거로만 다루도록 분석 파이프라인을 설계하라고 권했다.
