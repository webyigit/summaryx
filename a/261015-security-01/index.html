시스코 보안 이메일 게이트웨이 CVSS 9.8 결함 실제 악용…'인증 없이 파일 쓰기'

시스코가 '시큐어 이메일 게이트웨이'의 치명적 취약점(CVE-2026-76519, CVSS 9.8)이 실제 공격에 쓰이고 있다고 경고했다. 로그인하지 않은 원격 발신자가 장비 운영체제에 파일을 쓸 수 있는 결함으로, 시스코는 내부 점검에서 찾았고 10월 공격을 인지했다. 피해 장비 수나 공격 주체는 밝히지 않았다.

파일 평판(File Reputation) 서비스가 메일 정책에 켜져 있고 콘텐츠 스캐너 도구가 25.3.0.5525 미만일 때 영향을 받는다. AsyncOS 15.5.5-014·16.5.0-780이 수정 버전이며, 16.0은 수정 빌드가 없어 옮겨야 한다. 우회책은 없고, 침해된 가상 장비는 새 자격 증명으로 다시 구축하라고 권했다.

시스코는 9월 공개한 이메일 파싱 SQL 인젝션 결함(CVE-2026-76461)도 실제 악용 중이라고 밝혔다. 과거 중국 연계 조직 UAT-9686이 이 제품의 다른 제로데이를 악용한 바 있지만, 이번 공격과의 연관은 확인되지 않았다.
