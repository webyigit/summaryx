도커 허브, 2년간 남아 있던 '남의 이름으로 이미지 푸시' 결함 수정…CVSS 9.4

도커 허브에서 개인 계정을 조직 계정으로 바꿀 때 개인 액세스 토큰(PAT)이 조직 소유자로 지정된 다른 사용자에게 넘어가는 결함이 수정됐다. 이 결함으로 한 사용자가 다른 사람 이름으로 이미지를 푸시·풀·삭제할 수 있었다. 범위는 레지스트리에 한정돼 웹 화면 접근이나 비밀번호·이메일·2단계 인증 변경, 계정 탈취는 불가능했다. 도커는 CVSS 4.0 기준 9.4점, '긴급'으로 평가했다.

결함은 2024년 8월 26일부터 열려 있다가 올해 9월 30일 수정돼 약 2년간 존재했다. 도커는 10월 2일 영향받은 사용자에게 알리고 8일 넘어간 토큰을 비활성화했으며 12일 보안 공지를 냈다. 기간 중 모든 전환과 약 30만 4000건의 푸시를 검토한 결과 악용 흔적은 없었다고 밝혔다.

결함은 연구자 페테르 몰나르와 크리슈티안 호자크가 'GhostPat'으로 이름 붙여 제보했고, 도커는 4시간 안에 고쳤다. 서버 측 수정이라 사용자가 설치할 것은 없지만, 쓰지 않거나 모르는 토큰은 폐기하고 조직 자동화에는 조직 액세스 토큰을 쓰라고 권고했다.
