애플 연구진 '미니언즈' 공개…노는 맥 GPU 묶어 가상 GPU 클라우드로, 10시간 작업이 몇 분

애플이 사무실 등에서 쉬고 있는 애플 실리콘 맥의 GPU를 모아 대규모 머신러닝 추론용 '동적 가상 GPU 클라우드'로 쓰는 시스템 '미니언즈(Minions)'를 arXiv(2610.12970) 문서로 공개했다. 애플 연구진은 이미 내부에서 이 시스템을 쓰고 있다.

전제는 일상 업무 중 맥 GPU 대부분이 놀고 있다는 점이다. 시스템은 웹·API로 작업을 받아 PostgreSQL 메타데이터 저장소에 쌓는 중앙 서버, 각 맥에서 하위 작업을 로컬 GPU로 처리하고 결과를 저장하는 실행기, 연결 끊김·전원 차단 같은 장애를 감지해 다른 기기에 작업을 다시 맡기는 감시 모듈, 실시간 대시보드 4개로 이뤄졌다.

애플 시험에서 10시간 넘게 걸리던 일부 추론 작업이 추가 인프라 없이 몇 분으로 줄었다. 맥 미니·맥 스튜디오는 이미 썬더볼트 5 RDMA 클러스터링을 지원하지만, 미니언즈는 썬더볼트 없이도 동작하는 것으로 보여 기업이 장비를 더 사지 않고 처리 시간을 줄이는 데 쓸 수 있다는 분석이다.
