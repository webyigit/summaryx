Databricks Machine Learning Professional — MLOps까지 묻는 엔터프라이즈 ML 자격

Databricks Certified Machine Learning Professional은 기업 규모의 머신러닝 솔루션을 설계·구현·관리하는 능력을 평가하는 데이터브릭스의 상위 자격이다. Associate가 플랫폼 위의 기본 ML 작업을 본다면, Professional은 모델 운영(MLOps)까지 포함한 엔지니어링 역량에 무게를 둔다.

출제 비중은 모델 개발 44%, ML Ops 44%, 모델 배포 12%로 운영 영역 비중이 크다. 채점 대상 59문항을 120분 동안 객관식으로 풀고, 시험 보조 자료는 쓸 수 없다. SQL 문항은 ANSI SQL 표준을 따른다고 공식 페이지는 밝힌다.

응시료는 200달러이고 언어는 영어뿐이며, 온라인 또는 시험센터에서 감독하에 치른다. 필수 선수 조건은 없지만 시험 가이드에 나온 ML 작업을 1년 이상 해 본 경험을 권장한다. 유효기간은 2년이다.
