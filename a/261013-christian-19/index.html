"작은 교회도 안심 못해"…예장총회, 전국 교회에 교인정보 보안 강화 요청

대형교회 교인정보 유출 의혹이 잇따르자 대한예수교장로회총회가 10일 총회본부·산하 기관·노회·시찰회와 전국 교회에 '홈페이지 및 교인 정보 보안 관리 강화 요청' 협조문을 보냈다. 협조문은 여의도순복음교회와 사랑의교회 의혹을 언급하며 특정 교회만의 문제가 아니고, 규모가 작고 전담 인력이 없는 교회일수록 더 취약하다고 경고했다.

총회는 홈페이지·서버 전수 점검, 계정·접근 권한 관리, 소프트웨어 최신화, 교인정보 최소 수집·안전 보관, 외부 업체 관리, 사고 시 신속 대응의 6대 조치를 제시했다. 관리자 비밀번호 변경과 2단계 인증, 보관 정보 암호화와 정기 백업, 위탁 업체 계약서에 보안 책임 명시, 침해 의심 시 외부 접속 차단과 신고 등을 권고했고, 홈페이지가 없거나 관리가 어려운 교회 지원도 추진한다.

여의도순복음교회는 12일 외부 보안 전문기관과 유출 의심 자료 7건을 분석해 헌금 전표에는 개인 식별정보가 없었지만, 교인정보 변경이력에는 주민등록번호 변경기록 2629건 등이 포함됐다고 밝혔다. 비밀번호 변경과 취약점 점검, 방화벽 교체를 진행 중이다. 사랑의교회는 자체 조사를 이어가고 있다.
