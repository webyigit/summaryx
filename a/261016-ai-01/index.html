스페이스XAI '그록 보이스 3.0', 음성 AI 종합 지수 1위…응답 0.81초·분당 0.08달러 유지

스페이스XAI가 듣고, 추론하고, 도구를 부르고, 말까지 하는 음성 대 음성 모델 '그록 보이스 3.0'을 내놨다. API에서는 grok-voice-3.0으로 쓰고, grok-voice-latest 별칭도 이 모델을 가리킨다. 아티피셜 애널리시스(AA)의 음성 대 음성 지수에서 86.9점으로 1위에 올라 GPT-라이브-1(83.2), 제미나이 3.8 라이브(82.6), 이전 버전 그록 보이스 2.0(81.3)을 앞섰다.

세부 항목이 모두 1위는 아니다. 빅벤치 오디오는 98.5%로 4위, 음성 에이전트 과제 τ-보이스는 71.6%로 GPT-라이브-1(74.5%)에 뒤졌지만 이전 56.5%보다는 크게 올랐다. 첫 음성이 나오기까지 0.81초로 경쟁 모델(약 1.3초)보다 빠르고, 분당 0.08달러 가격은 그대로다. 웹 검색·X 검색·원격 MCP 서버 같은 도구를 대화 중에 바로 부르고, 기본 음성 28개와 120초 이내 음성 복제, 20개 언어 자동 감지를 지원한다.

가중치는 공개하지 않는 API 전용 모델이고, 파라미터 수나 구조도 밝히지 않았다. 회사는 음성을 저장하거나 학습에 쓰지 않는다고 했다. 기사는 수치 상당수가 AA와 회사 발표에 기댄 것이라며, 개발자는 별칭 대신 버전 이름을 고정해 쓰라고 권했다.
