아틀라시안 지라·컨플루언스 파일 열람 취약점, 패치 하루 만에 악용 시도

아틀라시안 데이터센터 제품의 파일 열람 취약점(CVE-2026-21589)을 노린 공격 시도가 패치 공개 하루쯤, 기술 분석 공개 몇 시간 만에 시작됐다. 위협 인텔리전스 기업 프레비디안은 6일(현지시간) 늦게 자사 허니팟에서 악용 시도를 확인하고 공격 IP 목록을 공유했다.

영향 제품은 비트버킷, 컨플루언스, 지라 서비스 매니지먼트, 지라 소프트웨어, 뱀부, 크라우드의 데이터센터 전 버전과 크루서블, 피셰이다. 공격에 성공하면 애플리케이션 서버의 파일을 읽을 수 있다. 와치타워는 공용 라이브러리의 경로 처리 문제를 원인으로 짚었고, 크라우드 연동 환경에서는 설정 파일의 평문 인증 정보를 통해 관리자 권한까지 얻을 수 있다고 분석했다. 아틀라시안은 공격자가 정확한 파일 경로를 알아야 한다고 설명했다.

아틀라시안은 가능한 빨리 업그레이드하고 접속 기록에서 침해 흔적을 점검하라고 권고했다. 바로 업그레이드가 어렵다면 취약한 서버를 인터넷에서 분리하거나 외부 접근을 막아야 한다.
