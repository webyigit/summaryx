KTR DR 플랫폼 시험평가용 UI 개발

한국화학융합시험연구원에서 'DR 플랫폼 시험평가용 UI 개발'을(를) 10월 8일 일반공고로 게시했다(공고번호 R26BK01763230-000). 사업 내용은 공고명 기준으로 DR(수요반응) 플랫폼 시험평가용 UI 개발이며, 배정예산은 29,000,000원, 추정가격은 26,363,636원이다. 계약방법은 일반경쟁이다.

입찰서 제출 마감은 2026-10-19 14:00, 개찰은 2026-10-19 15:00이다. 조달데이터 상세 화면에는 사업기간·낙찰자결정방법·참가자격·제안설명회와 세부 과업 내용이 나와 있지 않아, 참여를 검토한다면 나라장터 공고문과 제안요청서 원문에서 과업 범위와 참가 업종 제한을 반드시 확인해야 한다.
