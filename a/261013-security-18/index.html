북한 김수키, 보안 컨퍼런스 'KCSCON 2026' 사칭해 우크라이나 안보 전문가 노려

북한 연계 해킹조직 김수키가 국내 대형 보안 컨퍼런스 'KCSCON 2026'을 사칭해 우크라이나 외교·안보 전문가들을 겨냥한 사실이 드러났다. 지니언스 시큐리티 센터는 12일 '오퍼레이션 깃파워' 보고서에서 공격자가 깃허브·깃랩 같은 정상 개발 플랫폼을 악용해 악성코드를 퍼뜨리고 정보를 훔치려 했다고 밝혔다. KCSCON 시스템이 뚫린 것이 아니라 행사를 사칭한 공격이다.

공격자는 8월 6일 실제 행사 일정·장소·주최 정보를 담은 연사 초청 메일을 프로톤메일 주소로 보냈고, 첫 메일엔 악성 파일 없이 답장한 사람에게만 초청장으로 위장한 압축 파일을 보냈다. 8월 19일에는 유럽 정책연구소를 사칭해 러·북 군사협력 보고서 검토를 요청했고, 9월 16일에는 화상회의를 제안하며 가짜 로그인 페이지로 계정 정보를 노렸다. 가짜 줌 설치 파일도 발견됐다. 보고서는 대부분 실패했으며 계정 탈취나 정보 유출은 확인되지 않았다고 했다.

지니언스는 악성 LNK 파일 62개를 수집했고 일본어·한국어 미끼 문서도 확인했다. 북한군 러시아 파병 관련 정보 수집이 목적일 수 있다고 평가했으며, 문종현 센터장은 행위 기반 탐지와 위협 헌팅을, 기사는 요청 메일의 공식 주최 도메인·담당자 확인을 권했다.
