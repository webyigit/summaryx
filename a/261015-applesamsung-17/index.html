원 UI 9, 갤럭시 탭 작업 표시줄 '자동 숨기기' 부활…위치도 좌·중·우 선택

삼성전자가 원 UI 9 업데이트로 갤럭시 태블릿의 작업 표시줄 자동 숨기기 옵션을 되살리는 것으로 알려졌다. 원 UI 8에서 사라졌던 기능으로, 갤럭시 탭 S12 울트라를 쓰던 한 레딧 사용자가 발견했다.

자동 숨기기는 기본 설정으로 들어가며, 단독 덱스 모드에서는 작업 표시줄과 상태 표시줄을 함께 숨겨 앱·영상 화면을 넓힐 수 있다. 외부 모니터에 연결했을 때도 덱스 작업 표시줄을 숨길 수 있다. 그동안 일부 사용자는 굿락의 멀티스타 기능으로 비슷한 효과를 냈다.

제스처 내비게이션을 쓰면 작업 표시줄을 왼쪽·가운데·오른쪽으로 옮길 수 있고, 3버튼 내비게이션은 선택지가 적을 수 있다. 덱스 모드에서는 가운데 고정이다. 태블릿용 원 UI 9 정식 버전은 아직 널리 배포되지 않아 최종 반영 여부는 확정되지 않았다.
