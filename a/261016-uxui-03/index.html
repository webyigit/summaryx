"원클릭 생성 대신 '시행착오'를 남겨라"… AI 시대 공동 창작형 UI 패턴 5가지

생성형 AI가 과정을 통째로 자동화하면서 사용자가 결과물을 승인만 하는 '검품자'가 되고 있다는 문제의식에서 출발한 글이다. 일본 UX 디자이너 블로그 '고양이와 디자인'은 빠르고 완성도 높은 결과물은 편리하지만, 고민하고 반복하며 생기던 사고의 깊이와 발견, 결과물에 대한 주인의식이 사라지고 습관적 승인이 반복되면 허무감과 'AI 피로'로 이어진다고 짚는다.

설계 근거로는 직접 손댄 것에 더 큰 애착을 느끼는 IKEA 효과, AI를 내 의도대로 다뤘다는 자기효능감, 그리고 '마찰'의 재평가를 든다. 불편함을 없애는 것만이 좋은 UX가 아니라, 사용자가 멈추고 고르고 손대게 하는 '건강한 마찰'을 의도적으로 설계하자는 것이다.

글은 공동 창작형 UI 패턴 5가지를 소개한다. 완성품 대신 미드저니의 4개 변형처럼 아이디어의 씨앗을 보여주기, 노션 AI처럼 블록 단위로 생성 중간에 개입·수정하기, 런웨이 모션 브러시나 어도비 파이어플라이 스타일 강도처럼 수치 대신 감각적으로 미세 조정하기, 깃허브 코파일럿의 차이 표시처럼 AI안과 내 안을 나란히 비교해 병합하기, 챗GPT의 분기 편집처럼 시행착오 이력을 시각화하기다.

도입 방법으로는 리서치로 사용자가 고집하고 싶은 부분과 맡기고 싶은 반복 작업의 경계를 찾고, 초안(AI 주도)·편집(사용자 주도)·최종 조정(공동)으로 주도권을 나누며, 숙련도에 따라 자동화 비중을 조절하라고 제안한다. 앞으로 AI 제품의 경쟁력은 정확도나 속도보다 재미와 성취감 같은 '체험의 질'로 옮겨 갈 것이라는 전망이다.
