원 UI 9, 갤럭시 S25와 S26 무엇이 다를까…프로 동영상 프레임·24MP 촬영서 차이

삼성 원 UI 9 업데이트가 갤럭시 S25와 S26 시리즈에 어떤 기능을 주는지 샘모바일이 비교했다. S26 시리즈는 원 UI 8.5로 출시돼 일부 카메라 기능을 이미 갖고 있었다. 두 시리즈 모두 단체 영상에서 한 사람만 따라가는 영상을 만드는 '마이 팬캠', 통화 중 일정·현지 시간 등을 보여주는 '콜 브리프', 카드 구성을 바꿀 수 있는 나우 브리프, 홈 화면 검색용 파인더 바, 빅스비 위젯 등을 받는다.

카메라에서는 차이가 있다. 수평 고정 '슈퍼 스테디'는 S25에 새로 들어오고, 듀얼 레코딩 세로 분할 화면은 두 시리즈 모두 추가된다. 프로 동영상 프레임은 S26이 FHD·UHD에서 120·60·48·30·24·100·50·25fps를 지원하는 반면 S25는 120·60·30·24fps다. S26은 카메라 어시스턴트 앱으로 일반 사진 모드에서 24MP 촬영이 가능하지만 S25는 엑스퍼트 RAW 앱을 써야 한다.

FE 모델은 예외가 있다. S25 FE와 원 UI 9로 출시된 S26 FE 모두 콜 브리프를 지원하지 않으며, S25 FE는 아이폰·아이패드·맥과의 퀵 셰어 지원을 얻는다.
