데이터를 줄여 더 잘 배운다… 학습량 0.22%로 추론 성능 유지

대형 언어모델의 추론 능력은 크게 좋아졌지만, 점점 커지는 데이터로 학습하면 비용만 늘고 성능 향상은 따라오지 않는다. 연구진은 '추론 지도 데이터를 얼마나 줄여도 능력을 잃지 않을까'라는 질문에서 출발해, 불확실성을 기준으로 학습 데이터와 최적화 횟수를 단계적으로 줄이는 방법을 제안했다.

교사가 쓴 사고 과정(CoT)을 하나의 고정된 경로로 보지 않고, 중간 단계마다 몬테카를로 추론 트리를 만들어 과정 수준의 불확실성을 잰다. 이를 바탕으로 먼저 원본 데이터를 작은 핵심 집합으로 압축하고, 이어서 지도 미세조정 중 학생 모델의 학습 상태에 따라 예제를 실시간으로 골라 넣는다.

여러 추론 벤치마크와 모델 계열에서 전체 데이터 학습 대비 최적화 예산의 0.22%(450배 이상 적은 학습 노출)만으로 추론 성능을 유지하거나 높였다. 다른 학생 모델 계열, 블랙박스 교사, 약한 모델이 강한 모델을 가르치는 설정에도 적용됐다.
