래블업, 한국어 특화 LLM 드래프트 모델 오픈소스 공개…추론 가속 효과 영어 모델 수준

대형 언어 모델의 답변 속도를 높이는 방법 중 하나가 '투기적 디코딩'이다. 작은 드래프트 모델이 다음 토큰 여러 개를 미리 추측하면 큰 모델이 한꺼번에 검증하는 방식인데, 영어 데이터로 학습한 기존 드래프트 모델은 한국어에서 추측 적중률이 낮아 효과가 떨어졌다.

래블업은 z-lab의 DFlash 기법(토큰을 순차가 아닌 병렬로 한 번에 생성)을 적용하고 한국어 데이터로 학습한 'GLM-5.2-NVFP4-DFlash-ko'를 허깅페이스에 공개했다. Z.ai의 GLM-5.2를 엔비디아 NVFP4 형식으로 돌릴 때 쓰며, 실제 한국어 에이전트 트래픽에서 평균 수락 길이(MAL)가 에이전트 작업 2.71, 한국어 질의 2.77로 영어 DFlash 모델과 비슷했다. 영어 학습 모델은 1점대였다. 학습에는 과기정통부·NIPA 지원 사업으로 받은 B200 64장 클러스터를 썼다.

회사는 GLM-5.3-Flash용 한국어 드래프트 모델과 11B 규모 온디바이스 한국어 디퓨전 언어 모델도 개발 중이다. 신정규 대표는 영어 위주 드래프트 모델로는 한국어 가속 효과를 보기 어려웠다고 설명했다. 래블업은 13~19일 코스닥 상장 수요예측을 진행한다.
