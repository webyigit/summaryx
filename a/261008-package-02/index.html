꿀·땅콩버터가 치약 튜브에? 식품 패키지에 번지는 알루미늄 튜브

꿀, 땅콩버터, 고추 페이스트 같은 식품이 치약이나 물감에서 보던 알루미늄 튜브에 담겨 나오는 사례가 늘고 있다. 다이라인은 이 흐름을 짚으며 '꿀이 든 튜브'가 주는 묘하게 어색하면서도 즐거운 낯섦에 주목했다.

알루미늄 튜브는 1841년 화가용 물감 용기로 처음 등장했다. 기사는 이 형식이 끈적한 스프레드류에 오히려 기능적으로 더 낫다고 본다. 숟가락이나 칼 없이 바로 짜서 쓸 수 있고, 병 입구에 흘러내려 손이 끈적해지는 문제도 줄어든다.

짜고, 바르고, 닫는 단순한 사용 방식이 요즘의 간편 조리·간식 습관과 잘 맞는다는 점에서, 튜브는 점성 식품 패키지의 자연스러운 진화로 평가된다.
