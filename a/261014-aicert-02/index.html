AWS Securing Agent Identities Demonstrated — 에이전트 AI 신원·권한 보안 실습형 마이크로 자격(무료)

AWS가 9월 29일 에이전트형 AI 역량을 검증하는 마이크로 자격 2종을 내놨고, 그중 하나가 'AWS Securing Agent Identities Demonstrated'다. 객관식 없이 실제 AWS 환경에서 힌트 없이 시간 제한 실습 과제를 푸는 방식이다.

평가 내용은 에이전트 AI 워크로드의 신원·접근 관리 강화다. 자체 호스팅 에이전트용 워크로드 아이덴티티 발급, 태그 기반 접근 제어, 범위가 제한된 JWT 인가, 호출자별 SigV4·JWT 선택, 에이전트를 JWT 신원 검증으로 옮기기, 토큰 작업 감사 등을 다룬다. Bedrock AgentCore·Cognito·IAM·CloudTrail·CloudWatch·Systems Manager가 쓰인다.

AWS Skill Builder에서 구독 없이 무료로 응시할 수 있고 통과하면 Credly 디지털 배지를 받는다. 클라우드 보안 엔지니어와 에이전트 AI를 보호하는 솔루션 아키텍트가 대상이다. 시험 시간·언어·유효기간은 공개되지 않았다.
