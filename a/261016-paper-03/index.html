영상 질문 답을 '생성' 대신 '채점'으로… 100배 빨라진 VideoJev

멀티모달 LLM은 영상 속 특정 장면 찾기나 객관식 질문에 답할 때 글자를 하나씩 생성하는 방식을 쓴다. 연구진은 영상 이해와 상호작용을 '구조화된 결정 문제'로 보고, 답을 생성하는 대신 후보를 점수 매기는 모델 VideoJev를 제안했다.

사전학습된 멀티모달 LLM의 답 생성 부분을 공용 '결정 헤드'로 바꿔, 시간 구간과 텍스트 선택지를 영상 근거에 비춰 채점한다. 이렇게 시간 구간 찾기에서는 사건 구간을, 객관식 영상 질의응답에서는 답 선택지를 바로 얻는다. 질문이 시간차를 두고 들어올 때는 캐시 추론을, 여러 질문은 한 번에 처리하는 결합 추론을 지원한다.

VideoJev-4B와 35B-A3B는 시간 구간 찾기 벤치마크 3종에서 기반 모델보다 평균 mIoU가 각각 6.7점, 10.8점 높았고 2.8~3.1배 빨랐다. 영상 질의응답 4종에서는 기반 모델의 '생각 모드'와 비슷한 성능을 100배 넘게 빠른 속도로 냈다.
