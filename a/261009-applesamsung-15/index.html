삼성, 보급형 갤럭시 A17 5G에서 원 UI 9.5 시험 시작

원 UI 9.0 배포가 아직 끝나지 않았는데 삼성이 보급형 갤럭시 A17 5G에서 원 UI 9.5 시험을 시작했다. 팁스터 파하드 알리 자베드가 삼성 서버에서 새 펌웨어(A176BOXM8EZJ1)를 발견했다. 보통 고가 모델부터 시험한 뒤 중저가로 내려오는 만큼, 이른 시점이라는 평가다.

삼성은 두어 달 전 갤럭시 S26 시리즈에서 원 UI 9.5 시험을 시작했고, 지난달 Z 플립8·폴드8로 넓혔으며, 기사 전날에는 갤럭시 A57용 빌드도 서버에 올라왔다.

원 UI 9.5는 9.0과 같은 안드로이드 17 기반이지만 앱 잠금, 다크 모드용 어두운 아이콘, 더 부드러운 애니메이션, 새 지문 애니메이션, 카메라 UI 조정, 앱 미러링 등이 추가될 것으로 보인다. 출시일은 아직 알려지지 않았다.
