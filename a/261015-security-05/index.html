넥스트클라우드 내장 '콜라보라 CODE' 앱 결함 악용…서버에 웹셸 심어져

넥스트클라우드 서버에 문서 편집 기능을 붙이는 선택 앱 'Collabora Online - Built-in CODE Server'의 치명적 결함(CVE-2026-110447)이 악용돼 공격자들이 서버에 웹셸을 심었다. 앱의 로컬 문서 서버가 재시작·업그레이드·오류로 멈춰 있을 때 인증 없이 요청만으로 터질 수 있다.

26.4.303 이전 모든 버전이 영향을 받고, 독립형 콜라보라 온라인이나 Nextcloud Office 앱만 쓰는 경우는 해당하지 않는다. 피해 서버 수는 알려지지 않았지만 관리자 3명이 깃허브에 신고했고, 첫 공격 기록은 9월 10일이다. 루트 권한 탈취 증거는 없다.

콜라보라는 9월 11일 26.4.303에서 고쳤지만 릴리스 노트에 보안 수정이라고 알리지 않았고, 권고문과 CVE는 10월 14일에야 나왔다. 앱을 끄는 것만으로는 안 되고 업데이트하거나 삭제해야 하며, 넥스트클라우드 29 이하는 먼저 업그레이드가 필요하다. 앱 폴더의 낯선 PHP 파일과 웹 서버 로그도 점검하라고 권했다.
