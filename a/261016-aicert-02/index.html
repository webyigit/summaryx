Google Cloud Associate Data Practitioner — 데이터 수집부터 분석·머신러닝까지 묻는 입문 자격

Associate Data Practitioner는 구글 클라우드의 어소시에이트(Associate) 등급 데이터 자격이다. 구글 클라우드의 데이터 서비스로 데이터를 수집·변환하고 파이프라인을 관리하며, 분석·머신러닝·시각화까지 다루는 능력을 확인한다. AI 모델을 만들기 전 단계인 데이터 준비와 관리 역량을 검증한다는 점에서 머신러닝·AI 자격으로 가기 전 단계로 볼 수 있다.

평가 영역은 데이터 준비·수집, 데이터 분석·표현, 데이터 파이프라인 오케스트레이션, 데이터 관리 네 가지다. IaaS·PaaS·SaaS에 대한 기본 이해도 요구한다. 영역별 비중은 페이지에 없고 시험 가이드 PDF에서 확인하도록 안내한다.

시험은 2시간 동안 50~60문항(단일·복수 선택)을 풀며 응시료는 125달러(세금 별도)다. 영어·일본어로 볼 수 있고, 온라인 원격 감독 또는 피어슨 뷰 시험장에서 응시한다. 선수 자격은 없고 구글 클라우드에서 데이터를 다룬 경험 6개월 이상을 권장한다. 페이지는 최근 브랜드 변경을 반영해 곧 시험이 업데이트된다고 안내한다(날짜 미표기).
