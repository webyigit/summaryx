샤오미 MiMo-V2.6: 강화학습 규모를 키워 '스스로 나아지는' 옴니모달 모델

샤오미 LLM-Core 팀이 텍스트·이미지 등 여러 형식을 다루는 옴니모달 모델 MiMo-V2.6 제품군의 기술 보고서를 냈다. 핵심은 사후학습에서 강화학습(RL)에 쓰는 계산량을 크게 늘려 자기 개선 쪽으로 나아가는 것이다.

보고서는 RL 전에 멀티모달 데이터로 중간 학습을 하고, 최대 100만 토큰 길이의 맥락에서 비동기로 학습한다고 설명한다. RL 환경은 코드, 일반, 시각, 사이버 보안 과제까지 아우르며, 여러 답을 묶어 평가하는 '그룹 단위 에이전트 채점'으로 보상 신호를 만들고 보상 해킹을 막는 장치도 넣었다.

저자들은 학습 과정 기록, RL 환경, RL 프레임워크를 오픈소스로 공개한다고 밝혔다. 대형 모델의 RL 확장 과정을 외부 연구자도 살펴볼 수 있게 하겠다는 것이다.
