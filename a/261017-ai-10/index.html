에이전트 도구 8000개 다 안 읽어도 된다…아케이드닷데브 '툴 추천', 입력 토큰 비용 최대 37% 절감

AI 에이전트가 업무용 소프트웨어 안에서 권한을 통제받으며 일하도록 돕는 스타트업 아케이드닷데브가 '툴 추천(Tool Recommendation)' 기능을 내놨다. 도구 목록이 길어질수록 에이전트 지시문이 비싸지는 문제를 겨냥해, 긴 함수 목록을 대화에 다 싣지 않고도 알맞은 동작을 찾게 한다.

아케이드 카탈로그의 도구는 8000개가 넘고 전부 설명하면 약 175만 토큰이 든다. 툴 추천은 이를 '앱 찾기·관련 함수 요청·실행' 같은 몇 개 진입점으로 바꾸고, 작은 전용 모델이 후보를 검색·순위화해 짧은 목록을 돌려준다. 실제 실행할 동작은 에이전트의 모델이 고르며 MCP로 작동한다. 회사는 도구 탐색 토큰을 최대 91%, 100개 고정 도구 시나리오에서 입력 비용을 최대 37% 줄인다고 밝혔다.

다만 벤처비트는 코덱스·클로드 코드로 408개 세션을 실측한 결과 입출력 토큰 절감은 7.6%였다고 짚었다. 큰 도구 결과가 대화에 남으면 절감 폭은 5~7%로 줄고, 도구가 25~28개 미만이면 이득이 적다. 샘 파티 CTO도 추천 호출이 반복되면 비용이 오히려 늘 수 있다고 인정했다. 툴 추천 자체는 별도 요금이 없다.
