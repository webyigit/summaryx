"초거대 모델 없어도 된다"…스마트엠투엠, 폐쇄망 소형 보안 모델로 취약점 탐지

김호원 스마트엠투엠 대표(한국정보보호학회장)는 7일 '대한민국 사이버보안 컨퍼런스 2026'에서 온프레미스 LLM 기반 취약점 탐지 솔루션 'SmartX'를 소개했다. 그는 미토스급 프론티어 모델을 직접 운영하는 일은 기술보다 거대 GPU 투자 문제라며, 소형 특화 모델과 에이전트 협업으로 폐쇄망에서도 충분히 대응할 수 있다고 주장했다.

외부 AI를 API로 연결하면 공공기관·제조기업 내부 소스코드와 취약점 같은 민감 정보를 넘겨야 하는 부담이 크다는 것이 출발점이다. SmartX는 약 300억 매개변수 모델을 보안 특화로 추가 학습하고, 정보 수집·탐색·교차 검증·중복 제거를 여러 에이전트가 나눠 맡은 뒤 격리된 가상 환경에서 실제 악용 가능성까지 확인한다. Cybench 과제의 87.5% 이상을 풀었다고 밝혔다.

김 대표는 작은 모델도 에이전트 설계로 일정 성과를 내지만 결국 특화 모델이 필요하다고 봤다. 또한 AI가 허용 범위를 벗어나지 않게 운영 환경과 분리해 시험하고, 멀티모달 입력에 숨긴 악성 지시처럼 AI 자체를 노리는 공격에도 대비해야 한다고 강조했다.
