앤트로픽, 검증된 보안팀에 AI 사이버 기능 확대…"참여 기관이 취약점 12만9천 건 확인"

앤트로픽이 10월 6일 기존 사이버 검증 프로그램(CVP)과 '프로젝트 글래스윙'을 합친 확대 프로그램을 공개했다. 검증된 보안 전문가·기관이 허가된 업무에서 AI의 작업 차단을 덜 겪도록 해 취약점 분석과 모의해킹을 돕는 것이 목적이다. 업무 범위와 보안 요건을 확인한 뒤 클로드 오퍼스 5.5, 소넷 5.5, 미토스 5.1 등을 단계별로 제공한다.

권한은 사고 대응·악성코드 분석 중심의 방어용, 허가된 시스템 모의해킹을 더한 레드팀용, 전력망·항공·통신망 같은 핵심 시스템을 점검하는 일부 기관용 특수 등급으로 나뉜다. 레드팀용에서도 랜섬웨어 배포·물리적 피해·대규모 장애 유발은 막는다. 개인 연구자는 방어용만 신청할 수 있다.

앤트로픽은 글래스윙 참여 기관이 4~7월 최소 12만9천 건의 취약점을 확인했고, 그중 3만3천 건 이상이 '치명적'·'높음' 등급이었다고 밝혔다. 다만 기관별 분류 방식이 다르고 패치 건수를 공개한 곳은 절반이 안 돼, 발견 건수만으로 수정 여부를 판단하기 어렵다는 지적도 나온다. AI가 탐색 속도를 높여도 검증과 수정은 사람이 챙겨야 한다는 것이 기사의 결론이다.
