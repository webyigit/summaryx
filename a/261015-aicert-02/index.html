NVIDIA OpenUSD Development Professional(NCP-OUSD) — 3D 콘텐츠 파이프라인 개발 자격

NCP-OUSD는 엔비디아가 운영하는 중급(Professional) 자격으로, 3D 장면 기술 표준인 OpenUSD를 이용해 3D 콘텐츠 제작 파이프라인을 구축·유지·최적화하는 능력을 검증한다. 디지털 트윈·시뮬레이션처럼 AI와 3D가 만나는 분야의 OpenUSD 개발자, 시스템 통합 담당자, 파이프라인·데이터 엔지니어, 데이터 아키텍트가 대상이다.

출제 비중은 컴포지션 23%, 데이터 교환 15%, 파이프라인 개발 14%, 데이터 모델링 13%, 디버깅·문제 해결 11%, 콘텐츠 집계 10%, 시각화 8%, USD 커스터마이징 6%다. 장면을 여러 레이어로 조합하는 '컴포지션' 이해가 가장 중요하다.

시험은 120분 동안 60~70문항을 원격 감독 온라인으로 영어로 치르며 응시료는 200달러다. 응시하려면 Certiverse 계정이 필요하다. OpenUSD와 파이썬 또는 C++ 경험 2~3년, 또는 스터디 가이드 학습을 권장하며, 자격은 발급일로부터 2년간 유효하고 재응시로 갱신한다.
