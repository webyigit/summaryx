원 UI 9(안드로이드 17), 갤럭시 S23·폴드5·플립5·A56 등 8종에 정식 배포…한국부터

삼성전자가 안드로이드 17 기반 원 UI 9 정식 업데이트를 갤럭시 기기 8종에 추가로 배포하기 시작했다. 대상은 갤럭시 S23·S23+·S23 울트라, Z 폴드5·Z 플립5, 갤럭시 A56·A36·A27이다. 지난주까지 약 12종이 업데이트를 받은 데 이은 확대다.

9to5Google은 SamMobile을 인용해 이번에도 한국부터 배포가 시작됐다고 전했다. 삼성은 보통 하루 이틀 안에 다른 지역과 더 많은 사용자로 넓힌다. S23 시리즈의 경우 먼저 베타 프로그램에 참여했던 사용자부터 받으며, 순서는 기기마다 다르다.

매체는 원 UI 9를 매년 이뤄지는 안드로이드 OS 업그레이드로, 큰 변화는 아니라고 평가했다. 앞서 원 UI 9를 받은 기종에 이어 구형 플래그십과 중저가 A 시리즈까지 대상이 넓어졌다.
