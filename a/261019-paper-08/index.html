모의 앱에서 배운 실력이 실제 폰에서도… GUI 에이전트 훈련장 MAI-Gym

자동으로 채점 가능한 보상을 쓰는 온라인 강화학습은 수학·코딩·도구 사용에서 큰 성과를 냈지만, 화면을 보고 조작하는 GUI 에이전트에는 적용이 어렵다. 상호작용 환경을 돌리는 비용이 크고 현실적인 훈련 과제가 부족하기 때문이다.

MAI-Gym은 모바일·데스크톱·웹 환경에서 GUI 에이전트 평가, 데이터 수집, 온라인 RL 훈련을 하나로 묶은 공개 플랫폼이다. 평가와 훈련이 같은 실행 파이프라인을 써 행동이 일관되고, 기존 벤치마크 10개를 지원하며 환경을 최대 2만 개까지 동시에 돌린다. 초기화할 수 있는 모의 앱과 여러 앱을 잇는 시나리오, 실행으로 검증한 채점기를 갖춘 다양한 과제도 자동으로 만든다.

이를 이용해 모바일과 컴퓨터를 함께 다루는 9B 에이전트 MAI-Gym-9B를 훈련해 MobileWorld 78.4%, OSWorld-Verified 76.2%를 기록했고, 10B 미만 공개 GUI 에이전트 중 최고라고 밝혔다. 모의 기차표 예매 앱에서 한 RL 훈련이 실제 휴대폰의 진짜 앱으로 옮겨가 성공률이 28.8%에서 48.1%로 올랐다. 프레임워크·모의 앱·검증 과제 2,000개·모델 체크포인트를 공개할 예정이다.
