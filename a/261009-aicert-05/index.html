AWS Certified Machine Learning Engineer – Associate — 새 버전 MLA-C02 베타 시작

AWS Certified Machine Learning Engineer – Associate는 Amazon SageMaker 등 AWS ML 엔지니어링 서비스를 1년 이상 써본 실무자를 위한 Associate(중급) 자격이다. 현재 시험(MLA-C01)은 130분 65문항, 응시료 150달러이며 Pearson VUE 시험장이나 온라인 감독으로 볼 수 있다.

시험이 개편 중이다. 공식 페이지에 따르면 새 버전 MLA-C02 등록이 2026년 9월 1일 열렸고 베타 시험은 9월 29일부터 시작됐다. 베타는 170분 85문항, 베타 응시료 75달러, 영어 전용이다. 생성형 AI·에이전틱 AI·파운데이션 모델·책임 있는 AI 내용이 추가되지만 도메인 구조는 그대로라고 한다.

영어 MLA-C01은 2026년 9월 28일로 끝났고, 한국어·일본어·중국어(간체) MLA-C01은 MLA-C02가 정식 출시될 때까지 유지된다. 한국어로 응시하려는 사람은 당분간 기존 MLA-C01을, 저렴하게 새 버전을 먼저 보려는 사람은 영어 베타를 고르면 된다.
