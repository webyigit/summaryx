SparseEngine: 희소 어텐션을 처음부터 중심에 둔 LLM 추론 엔진

오래 작업하는 LLM 에이전트는 대화 기록이 계속 쌓여 KV 캐시 메모리와 어텐션 계산 부담이 커진다. 희소 어텐션은 이 비용을 줄일 수 있지만, 방법마다 캐시 형식과 작업 흐름이 달라 기존 추론 엔진에 끼워 넣기 어렵고, 이전 희소 서빙 설계는 특정 구조만 지원했다.

SparseEngine은 희소 어텐션을 기본 전제로 새로 설계한 추론 엔진이다. 공통 '생애주기 계약'을 둬 각 방법이 자기 KV 표현과 계산을 관리하면서도 공통 서빙 인프라와 맞물리게 했다. 4개 범주 15개 방법을 지원하며, KV 축출 방법이 남은 기록에서 이어 가게 하는 Chain Cache와, 선택한 기록 구간의 KV를 지우면서도 논리적 접두어 일치는 유지하는 접두어 캐시 가지치기로 요청 간 상태를 관리한다.

방법별 품질을 유지하면서 KV 축출 시 처리량 10배 이상, 같은 동시성에서 vLLM보다 디코딩 2.5배 이상 빠르고, 에이전트 벤치마크 전체 처리 속도는 2배 이상 빨라졌다고 연구진은 보고했다.
