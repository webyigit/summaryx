알리바바, 생성 단계 40→8로 줄인 '큐원 이미지 2.1 터보' 공개…장당 0.1위안

알리바바가 9일(현지시간) 기존 '큐원 이미지 2.1'을 바탕으로 속도를 높인 이미지 생성·편집 모델 '큐원 이미지 2.1 터보'를 내놨다. 70억 매개변수 구조와 2K 해상도 생성·편집 기능은 그대로 두고, 확산 모델이 노이즈를 걷어내는 디노이징 단계를 40단계에서 8단계로 줄인 것이 핵심이다. 다만 모델 로딩·디코딩 시간 때문에 전체 생성 시간이 5분의 1로 줄지는 않는다.

인물·포즈, 투명 배경, 포스터·타이포그래피, UI 레이아웃 생성과 여러 참조 이미지 조합을 지원한다. 텍스트·이미지 처리에는 80억 매개변수 'Qwen3-VL 8B' 인코더를 쓰고, 첫 단계 계산을 재사용하는 접두부 KV 캐싱으로 연산을 줄였다.

알리바바 클라우드 API 가격은 장당 터보 0.1위안, 프로 0.25위안으로 터보가 60% 싸다. 가중치는 허깅페이스·모델스코프에 비상업 라이선스로 공개됐고, 터보가 원본 품질을 유지하는지는 독립 검증되지 않았다.
