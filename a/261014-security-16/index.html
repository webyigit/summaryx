금융보안원, 실행 중 정보 흐름 추적하는 AI 모바일 앱 보안 탐지 기술 ISSTA 채택

금융보안원이 자체 개발한 AI 기반 모바일 앱 보안 위험 탐지 기술이 국제 소프트웨어공학 학회 ISSTA 2026에 채택됐다. 송성현 팀장이 제1저자로 참여한 논문은 여러 단계 심사를 거쳐 2026년 6월 정규 논문으로 선정됐고, 10월 4일부터 9일까지 미국 캘리포니아에서 열린 학회에서 발표됐다.

이 기술은 앱 소스코드뿐 아니라 실제 실행 중의 동작과 정보 흐름까지 분석한다. 앱은 외부 라이브러리와 운영체제 기능이 얽혀 있어 코드만 봐서는 실행 시점의 위험을 드러내기 어려운데, 실행 중 정보 흐름을 추적해 이 빈틈을 메운다는 설명이다. 실제 모바일 앱 50개에 적용한 시험에서 보안 취약점 17개를 찾아냈다.

금융보안원은 이를 바탕으로 AI 기반 점검 체계를 만들어 금융권 모바일 앱 보안 점검에 적용하고, 점검 데이터와 새 위협 사례를 다시 반영해 기술을 고도화할 계획이다. 박상원 원장은 연구 성과를 금융 현장에 적용해 보안 수준을 높이겠다고 말했다.
