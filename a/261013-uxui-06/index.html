"모든 애니메이션은 기능을 위해"… 호버·모션에 집중한 UI 컴포넌트 라이브러리 '플루이드 펑셔널리즘'

디자인 링크 큐레이션 사이트 사이드바(Sidebar)가 10월 12일 소개한 '플루이드 펑셔널리즘'은 디자이너 @micka_design이 만든 UI 컴포넌트 라이브러리다. '만족스러운 호버를 가진 정제된 UI 컴포넌트'를 내세우며, 모션이 장식이 아니라 정보를 전달해야 한다는 '모든 애니메이션은 기능적 목적을 가진다'는 원칙을 핵심 철학으로 삼는다.

파운데이션 영역에서 호버, 모션, 스크롤바, 크기, 서피스, 타이포그래피를 정의하고, 아코디언·버튼·콤보박스·다이얼로그·슬라이더·탭·툴팁 등 28개 컴포넌트를 문서화했다. AI 제품용으로 '생각 중' 표시(ThinkingIndicator), 단계 표시(ThinkingSteps), 채팅 메시지 같은 컴포넌트도 들어 있다. 모션은 빠름·보통·느림 등 스프링 프리셋으로 고를 수 있다.

기본 접근성, 다크 모드, 키보드 내비게이션, 테마·라운드·크기·아이콘 세트 설정을 지원하고, Radix나 Base UI 프리미티브와 호환되며 shadcn/ui 레지스트리로 설치한다. 인터랙션 디테일을 디자인 시스템 수준에서 정리한 사례로 참고할 만하다.
