세계 모델로 AI의 '재귀적 자기 개선'을 여러 분야에 적용

재귀적 자기 개선(RSI)은 시스템이 상호작용 경험을 쌓아 지속적인 성능 향상으로 바꾸는 것을 말한다. 연구진은 외부 피드백을 얻는 비용이 비싸고, 정책이 바뀌면 세계 모델의 예측이 덜 믿을 만해진다는 두 가지 걸림돌을 지적했다.

RSI-Anything은 JEPA-Anything을 바탕으로 한 범용 틀로, 예측형 세계 모델을 이용해 어떤 행동을 할지, 어떤 데이터로 배울지를 고른다. 실제로 관측한 피드백으로 정책이나 작업 흐름을 개선하고 필요하면 세계 모델도 맞춘다. 구성 요소·호환성 검사를 통과한 정책-모델 쌍만 유지한다.

코드 수정 성공률은 고정 검증기 26.3%에서 예측 기반 선택 29.2%, 세계 모델 적응 후 31.2%로 올랐다. GUI 작업에서는 평균 행동 수가 39.4% 줄었고, 실험실 계획 점수는 정책 5세대에 걸쳐 21.80%에서 46.01%로 두 배 넘게 뛰었다. 실험 40회 예산의 반응 최적화에서는 평균 최고 수율 96.15%로 베이지안 최적화(82.16%)를 앞섰다.
