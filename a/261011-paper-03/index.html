Trace2Env: 옛 사용 기록만으로 AI가 '가짜 환경'을 연기하게 하다

에이전트를 훈련·평가하려면 상대할 환경(웹사이트, 업무 시스템 등)이 필요하지만, 원래 시스템을 쓸 수 없거나 새로 구현하기 어려운 경우가 많다. 이 논문은 실행 가능한 시스템을 다시 만드는 대신, 언어모델 에이전트가 환경 역할을 맡는 '에이전트형 언어 월드 모델'을 제안했다.

핵심 틀인 Trace2Env는 별도 학습 없이, 과거에 쌓인 상호작용 기록(트레이스)을 재사용 가능한 '환경 월드북'으로 정리한다. 실행 중에는 환경 역할 에이전트가 이 월드북과 지속되는 에피소드 상태를 참고해 다음 화면·응답을 만들어 낸다.

9개 환경에서 프롬프트만 쓴 기준선보다 다음 관찰을 더 정확히 재현하고 긴 상호작용에서도 일관성이 높았다. 이 가짜 환경에서 만든 행동을 실제 환경에 다시 돌려도 유효한 경우가 더 많았다고 한다.
