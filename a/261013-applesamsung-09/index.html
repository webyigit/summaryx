갤럭시 S24 시리즈, 원 UI 9.0 정식 업데이트 미국 도착…통신사 모델부터

삼성전자가 안드로이드 17 기반 원 UI 9.0 정식 업데이트를 미국의 갤럭시 S24·S24+·S24 울트라에 무선(OTA)으로 배포하기 시작했다. 우선 통신사 전용(캐리어 락) 모델부터 받고 있으며, 자급제(언락) 모델도 곧 받을 것으로 보인다.

레딧 게시물에 따르면 S24 울트라용 업데이트 용량은 3909.81MB, 펌웨어 버전은 S928USQU6EZIF다. 정식 버전은 한국에서 먼저 배포된 뒤 유럽·인도 등으로 확대됐고, 같은 날 미국에도 풀렸다. 설정 > 소프트웨어 업데이트 > 업데이트 확인에서 받을 수 있다.

원 UI 9.0은 원 UI 8.5에 비해 더 자유롭게 꾸밀 수 있는 퀵 패널, 강화된 삼성 덱스, 삼성 노트·접근성 개선, 위치 정보 사용 표시, 다양한 AI 기능을 담았다. 원문에는 보안 패치 수준이나 자급제 모델 배포 날짜는 나오지 않는다.
