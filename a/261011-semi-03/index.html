엑시나, 포트래이와 CXL 메모리로 바이오 빅데이터 인프라 구축 협약

팹리스 엑시나(XCENA)가 공간 오믹스 전문 테크바이오 기업 포트래이와 CXL(컴퓨트 익스프레스 링크) 기반 대규모 생물정보 분석 인프라를 함께 구축하는 업무협약을 맺었다. 세포 수가 늘수록 급증하는 공간 오믹스 데이터를 고성능·저비용으로 처리하는 CXL 컴퓨팅 시스템을 개발·검증하는 것이 목표다. 유전자 분석 해상도를 높이려면 서버 한 대에 큰 메모리가 필요한데, 기존 D램의 한계가 걸림돌이었다.

협약에 앞서 두 회사는 10x 지노믹스 기술 기반의 포트래이 분석 파이프라인 'ATERA'를 엑시나의 메모리 확장 솔루션 '인피니트 메모리'에서 시험했다. 이 솔루션은 SSD를 CXL 장치에 직접 연결해 소프트웨어 수정 없이 시스템 메모리를 늘리는 방식으로, 약 3500만 개 세포 규모 데이터 분석에 성공했다. 앞으로 분석 규모를 1억 개 세포까지 늘릴 계획이다.

엑시나는 차세대 CXL 메모리 솔루션 'MX1'을 포트래이 인프라에 적용해 D램과 SSD를 결합한 상용 시스템을 만들고, CXL 활용처를 AI 추론에서 바이오 빅데이터로 넓힐 방침이다. 김진영 대표는 이번 협약이 CXL 메모리를 실제 바이오 데이터 현장에 적용하는 출발점이라고 말했다.
