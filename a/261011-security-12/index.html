두나무 "'조회만 한다'며 업비트 API 키·계정 빌려달라는 SNS 사기 주의"

업비트를 운영하는 두나무가 SNS에서 업비트 계정이나 조회 전용 API 키를 빌리거나 사겠다는 메시지가 퍼지고 있다며 투자자 주의를 당부했다. 사기범들은 입출금이나 거래 없이 시세 데이터만 보겠다며 안심시키지만, 업비트 시세 데이터는 인증 없이 쓰는 공개 API로 제공돼 계정을 빌릴 이유가 없다.

API 키가 넘어가면 권한에 따라 자산·주문·입출금 정보 조회나 거래 기능까지 악용될 수 있다. 두나무는 계정 대여나 키 제공으로 생긴 피해의 책임이 회원에게 있다고 밝혔다. 회사는 출금 권한이 있는 키도 앱에서 '출금 허용'을 직접 켜야 출금되게 하고, 등록되지 않은 IP에서 호출이 오면 카카오톡 알림톡으로 알린다.

대여에 쓰인 계정은 즉시 이용을 정지하고 필요하면 수사기관에 고발하는 등 무관용으로 대응할 방침이다. 두나무는 API 키를 넘기는 것은 "금고 열쇠를 낯선 이에게 쥐여주는 것"과 같다고 경고했다.
