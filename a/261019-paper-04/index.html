화면 클릭에 코드 실행까지… 범용 '컴퓨터 사용' 에이전트 전 과정 공개한 OpenGCUA

AI가 사람 대신 컴퓨터를 조작하는 '컴퓨터 사용' 에이전트는 화면을 보고 클릭하는 방식에서, 프로그램 인터페이스를 직접 다루는 방식까지 아우르는 쪽으로 발전하고 있다. 하지만 GPT-6 Astra의 컴퓨터 사용 시스템 같은 선두 구현은 비공개라 연구하기 어렵다는 것이 연구진의 문제의식이다.

OpenGCUA는 화면을 어떻게 볼지, 어떻게 행동할지, 일을 어떻게 나눌지를 모델 스스로 정하는 '범용 컴퓨터 사용 에이전트(GCUA)'의 전체 스택을 공개하려는 커뮤니티 프로젝트로, 이번이 첫 공개다. 에이전트가 코드를 실행해 중간 결과를 보고 다음 행동을 정하게 했고, 관찰·작업 상태에 대한 결정을 사람이 짠 고정 규칙에서 모델로 넘기는 '하네스→모델 결정 이전'을 제안했다.

OSWorld-v2에서 GPT-6 Astra, Claude Opus 5 등 시험한 8개 모델 모두 점수가 올랐고, 평균 부분 점수는 19.6점 오르고 과제당 단계 수는 GUI만 쓰는 방식보다 53.0% 줄었다. 실제 macOS 과제 4개 시험에서는 Qwen3.8-Max가 GPT-6 Astra보다 추론 토큰을 19.4배 써 모델 간 효율 차이가 컸다. 구현·프롬프트·8개 모델 실행 기록과 실기기 하네스·기기 공통 SDK 초기판을 함께 공개했다.
