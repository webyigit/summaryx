'개인정보 유출' 여의도순복음·사랑의교회, 보안 대응 체계 가동

해킹으로 교인 정보 유출 정황이 드러난 서울의 대형교회들이 보안 강화에 나섰다. 여의도순복음교회는 11일 IT 담당자와 시스템 개발·유지보수 업체, 외부 보안 전문업체 인력으로 대응 체계를 가동했다고 밝혔다. 침해 통보를 받은 직후 서버·방화벽 접속 기록을 분석하고 악성코드 삭제와 외부 접속 차단 조치를 했다.

교회는 유출 의심 자료 7건 중 성도 정보 변경 이력 1건에서 일부 개인정보가 확인됐고, 과거 헌금 전표에는 개인 식별정보가 없었다고 설명했다. 해당 성도에게는 개별 통지와 보호 조치를 진행하고 보안 장비와 접근 권한 관리 체계를 강화할 방침이다.

사랑의교회도 10일 성도들에게 문자를 보내 이름·생년월일·전화번호·주소와 일부 교적 정보에 비정상적 외부 접근 정황을 확인했다고 알렸다. 즉시 외부 접근을 차단하고 재발 방지책을 마련 중이며, 교회 사칭 연락이나 출처 불명의 링크, 개인·금융정보 요구에 응하지 말라고 당부했다. 전체 유출 규모나 공격 주체는 기사에 나오지 않았다.
