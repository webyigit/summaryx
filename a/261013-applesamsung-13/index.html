갤럭시 S23도 곧 원 UI 9.0…'마지막 메이저 업데이트' 될 듯

삼성전자의 원 UI 9.0 정식 업데이트가 곧 갤럭시 S23 시리즈에도 배포될 전망이다. 샘미팬즈는 S23이 다음 차례라며, S22처럼 S23도 원 UI 9.5는 받지 못해 이번이 마지막 메이저 업그레이드가 될 수 있다고 전했다.

원 UI 9.0 정식 배포는 9월 중순 시작됐다. 삼성은 약 2주 만에 전 세계 S26 사용자에게 배포를 마쳤고, 이후 S25·S24 시리즈와 다른 구형 플래그십으로 넓혀 왔다. 샘미팬즈는 S23 배포는 확실하고 날짜만 미정이라며, 삼성 소식에 밝은 @ya_sking12767이 다음 주 월요일이나 화요일 배포 시작을 점쳤다고 전했다.

전 세계 확대에는 시간이 걸려 10월 말께 최신 보안 패치와 함께 폭넓게 풀릴 것으로 예상했다. 원 UI 9.0은 안드로이드 17 기반으로 슬라이더가 두꺼워진 퀵 패널, 새 굿락 기능 등을 담았다.
