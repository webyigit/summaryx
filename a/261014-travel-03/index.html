TUI 벨기에 고객에 '예약 정보 그대로' 사기 메시지…회사, 데이터 유출 조사

여행사 TUI 벨기에가 데이터 유출을 확인하고 국제 조사팀을 꾸려 조사에 나섰다. 고객들이 실제 휴가 예약 내용이 담긴 사기 메시지를 받았다고 신고하면서다. 원인과 피해 범위는 아직 밝혀지지 않았다.

고객들은 왓츠앱과 이메일로 모르는 발신자의 연락을 받았는데, 메시지에는 이름과 예약한 호텔, 정확한 여행 날짜가 적혀 있었고 일부는 예약 금액까지 들어 있었다. 메시지는 링크를 눌러 예약을 확인하거나 결제 정보를 입력하고 선금을 보내라고 유도했다.

TUI는 유출 사실은 인정했지만 피해 고객 수와 노출된 정보, 피싱에 쓰인 데이터가 자사에서 나간 것인지는 확인하지 않았고, 자사 IT 시스템이 직접 공격받았는지도 확인되지 않았다. 대변인은 11일 네덜란드 ANP 통신에 현재로선 벨기에 고객만 해당되고 네덜란드 고객은 영향이 없어 보인다고 밝혔다. 기사는 예약 정보가 정확하다고 진짜 메시지라는 증거는 아니라며, 의심스러운 링크·결제 요청을 피하고 TUI 공식 채널로 직접 확인하라고 권했다.
