앤트로픽, '증류 공격' 방어 체계로 추론 데이터 추출 최대 99% 감소

앤트로픽이 12일(현지시간) 공식 블로그를 통해 '증류(distillation) 공격'에 대응하는 새 보안 체계를 도입해 추론 데이터 추출을 최대 99% 줄였다고 밝혔다. 증류는 원개발사 허락 없이 특정 AI 모델의 능력을 뽑아내 다른 모델에 복제하는 것으로, 공격자는 다수의 가짜 계정과 프록시 접속망으로 고성능 AI에 반복 질의해 그 답과 추론 과정을 자기 모델 학습에 쓴다. 앤트로픽은 중국 지푸AI가 'GLM-5.3'을 개발하며 사이버 공격 능력을 포함한 미국 선두 모델의 능력을 증류했다며 국가안보 위험을 경고했다.

방어책은 세 가지다. 새 API 계정이 기존 대화의 추론 맥락을 수정하지 못하게 하는 등 추론 정보 접근을 제한했고, Claude의 숨은 추론 과정을 빼내려는 요청을 찾는 2단계 분류기를 배치해 오탐률을 0.1% 미만으로 낮췄으며, 악성 계정을 차단했다. 그 결과 공격자가 뽑아낸 추론 토큰이 이전보다 10~100분의 1로 줄었고, 관련 계정 수만 개를 차단했으며 일부는 공격 시작 2시간 안에 잡아냈다.

앤트로픽은 정교한 공격을 장기적으로 막을 수 있을지는 아직 확신할 수 없다고 인정했다. 상당한 유료 트래픽과 매출을 포기했다며, 공격이 여러 클라우드·AI 서비스에 분산되는 만큼 모델 개발사와 플랫폼 운영사의 공조를 촉구했다.
