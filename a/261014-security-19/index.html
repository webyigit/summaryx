구글 개발자 문서 사이트, 계정 없이 서버 코드 실행 가능한 결함…포상금 9만 달러

구글 개발자 문서 사이트들이 함께 쓰는 플랫폼 'DevSite'에서 구글 계정 없이도 서버에서 코드를 실행할 수 있는 결함이 발견돼 10월 7일 수정됐다. 보안 연구원 시몬 쾨크(Simon Koeck)가 8월 제보했고, 구글은 취약점 보상 프로그램으로 9만 달러를 지급했다. developers.google.com, firebase.google.com, developer.android.com 등이 같은 OAuth 로그인 과정을 써 영향이 개발자 사이트 전반에 미칠 수 있었다.

원인은 로그인 때 발급되는 Flask 세션 쿠키가 서명만 되고 암호화되지 않아 내용을 누구나 읽을 수 있었던 데 있다. 쿠키에는 OAuth 클라이언트 시크릿이 들어 있었는데, 이 값이 쿠키 서명 키로도 쓰여 세션 쿠키를 위조할 수 있었고, 서버는 세션 데이터를 그대로 역직렬화 처리했다. 연구원은 실제 명령은 실행하지 않고 응답을 일정 시간 늦추는 무해한 코드로 실행 가능성만 입증했다.

구글은 노출된 시크릿을 교체하고 해당 키로 서명된 세션을 무효화했으며, 서명 키와 OAuth 자격 증명을 분리하고 관련 객체를 서버 측 저장소로 옮겼다. 실제 악용 여부는 알려지지 않았다. 기사는 쿠키에 민감한 상태값을 두지 말고, 외부에서 바꿀 수 있는 데이터는 JSON 같은 데이터 전용 형식과 구조 검증으로 다루라고 권고했다.
