디노티시아 "다음 병목은 데이터"…검색 전용 칩 VDPU 공개

디노티시아 정무경 대표는 7일 'AI 페스타 26'에서 AI 에이전트 시대에는 데이터센터 병목이 GPU에서 CPU와 메모리로 옮겨가고 있다고 진단했다. RAG와 추론, 에이전트로 발전하며 한 과업에 필요한 데이터 검색이 크게 늘었고, 지금 데이터센터 CPU 작업량의 60~70%가 데이터 탐색에 쓰인다는 설명이다. KV 캐시도 커져 HBM에 다 담기지 못하고 밖으로 옮겼다 다시 불러오며 지연이 생긴다.

디노티시아의 해법은 의미 기반 검색에 특화된 칩 VDPU다. 검색 알고리즘 속도를 CPU 대비 최대 15배 높이고, 찾은 데이터를 CPU를 거치지 않고 GPU 메모리에 바로 쓰는 제로 카피 기술로 이동 지연을 줄인다. 3년 전부터 개발해 왔다.

회사는 VDPU에 외부 지식·장기 기억·KV 캐시를 함께 관리하는 소프트웨어를 얹은 AI 스토리지를 GPU 옆에 두는 구상을 내놨다. 기업 데이터의 75~85%가 쓰이지 않는 다크 데이터라는 점도 기회로 봤다.
