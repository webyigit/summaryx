주니퍼, Junos 결함 150여 개 한꺼번에 패치…F5도 NGINX 결함 11개 수정

네트워크 장비 업체 주니퍼 네트웍스가 권고문 17건을 내고 Junos OS와 Junos OS Evolved의 보안 결함 150여 개, 클라우드 네이티브 라우터(JCNR) 결함 4개를 고쳤다. 이 가운데 약 20여 개가 치명적 등급으로, 루트 권한 코드 실행이나 장비 장악, 커널 패닉·재부팅 같은 서비스 중단으로 이어질 수 있다.

F5도 권고문 K000163408로 NGINX 결함 11개를 수정했다. 치명적 결함 2개(CVE-2026-15176, CVE-2026-93479)는 인증 없이 조작된 HTTP 요청으로 버퍼 오버플로를 일으켜 서비스를 재시작시키고, 메모리 주소 무작위화(ASLR)가 꺼져 있거나 우회되면 원격 코드 실행도 가능하다. 나머지는 검증 우회·정보 노출·요청 위조 등이다.

두 회사 모두 실제 악용 사례는 언급하지 않았다. 해당 제품을 쓰는 곳은 각 권고문을 확인해 업데이트를 적용해야 한다.
