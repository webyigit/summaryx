워드프레스 플러그인 '브릭스포지' CVSS 10.0 결함 실제 악용…인증 없이 원격 코드 실행

워드프레스 보안업체 패치스택(Patchstack)이 플러그인 '브릭스포지(Bricksforge)'의 최고 위험도(CVSS 10.0) 취약점 CVE-2026-85097이 실제 공격에 쓰이고 있다고 밝혔다. 로그인하지 않은 공격자가 PHP 파일을 올려 실행할 수 있어 사이트 전체가 장악될 수 있다. 3.1.8.9 이하 버전이 영향을 받는다.

패치스택은 10월 7일 처음 악용을 탐지했으며, 63개 IP에서 공격이 들어왔고 그중 6개가 요청의 약 46%를 차지했다. 자동화된 공격으로 보이나 특정 조직으로 지목하지는 않았다. 수정 버전은 워드펜스 기준 3.1.8.10이지만 기사는 4.0.1로 올릴 것을 권했다.

같은 기사는 'WPC 제품 번들'과 '닌자 폼' 플러그인의 XSS 결함을 통해 백도어 플러그인과 숨은 관리자 계정을 만드는 공격도 함께 전했다. 업데이트만으로는 이미 심긴 감염이 지워지지 않으므로 업로드 폴더의 낯선 파일, 숨은 관리자 계정, mu-plugins 폴더를 함께 점검해야 한다.
