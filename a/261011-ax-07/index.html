엑스알리더, 로봇이 돌며 자동 갱신하는 디지털트윈 'AX-CLOUD' 개발

디지털트윈 기업 엑스알리더가 산업현장의 공간 변화를 자동으로 반영하는 AI 플랫폼 'AX-CLOUD'를 개발한다. 경기콘텐츠진흥원 '2026년 AI 콘텐츠 허브 특화 프로그램' 지원 과제다. 기존 디지털트윈은 재촬영과 수동 업로드가 필요해 구축 당시 모습에 머물기 쉬웠다는 문제를 겨냥했다.

자율이동로봇(AMR)에 탑재된 촬영장비가 현장을 돌며 공간을 기록하면 데이터가 클라우드로 자동 전송되고, 자체 엔진 'AX Twin Engine'이 최신 공간으로 정합한다. 이어 AI가 이전과 현재를 비교해 설비 이동·적치물 변화·통로 장애물을 찾아내 웹 XR 콘텐츠, 대시보드, 자동 리포트로 제공한다. 자체 장비 '매트릭스360'을 소프트웨어·API로 연동해 특정 로봇 제조사에 묶이지 않는다.

현재 로봇물류센터 테스트베드에서 360° 데이터를 반복 취득하며 영상·열화상 정합도 검증했고, KT Cloud 인프라를 쓴다. 공간 데이터 처리 시간 60% 이상 단축, 변화감지 정확도 80% 이상이 목표이며, 연내 파일럿 v1.0으로 제조현장 적용성을 검증할 계획이다.
