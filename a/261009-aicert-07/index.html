Microsoft Azure AI Engineer Associate(AI-102) — 자격·갱신 평가 은퇴

Microsoft Certified: Azure AI Engineer Associate는 AI-102 시험으로 따던 Azure 기반 AI 솔루션 엔지니어용 중급(Intermediate) 자격이다. 시험 시간은 100분이었고 한국어를 포함해 10개 언어로 제공됐다.

그런데 현재 Microsoft Learn 공식 페이지 상단에는 '이 자격증과 갱신 평가는 은퇴(retired)했다'는 경고가 붙어 있고, 해당 시험의 교육 과정도 더는 제공되지 않는다고 표시돼 있다. 은퇴 일자와 대체 자격은 페이지에 명시되지 않았고, 'AI 일자리 붐' 관련 Microsoft 블로그 글로 연결만 돼 있다.

AI-102 대비 자료를 보고 있던 수험생이라면 더 이상 이 자격을 새로 딸 수 없으니, Microsoft Learn 자격증 목록에서 현재 제공되는 AI 관련 자격을 확인하고 학습 계획을 다시 세워야 한다.
