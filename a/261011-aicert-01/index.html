NVIDIA Generative AI LLMs Professional(NCP-GENL) — LLM 최적화·배포까지 묻는 중급 자격

NCP-GENL은 엔비디아가 운영하는 대규모 언어모델(LLM) 분야의 프로페셔널(중급) 자격이다. 입문 단계인 NCA-GENL 다음 단계로, 대상은 소프트웨어 개발자·엔지니어, 솔루션 아키텍트, ML 엔지니어, 데이터 과학자, 생성형 AI 전문가다. LLM을 다뤄 본 실무 경험 2~3년 정도를 권장한다.

출제 비중은 모델 최적화 17%, GPU 가속·최적화 14%, 프롬프트 엔지니어링 13%, 파인튜닝 13%, 데이터 준비 9%, 모델 배포 9%, 평가 7%, 운영 모니터링·신뢰성 7%, LLM 구조 6%, 안전·윤리·규정 5%다. 트랜스포머 구조, 분산 병렬화, 파라미터 효율적 미세조정, 환각 완화, RAG, 평가 지표 등을 알아야 한다.

시험은 120분 동안 60~70문항을 원격 감독 온라인으로 보며, 응시료는 200달러, 언어는 영어다. 자격은 발급일로부터 2년간 유효하고 다시 시험을 봐서 갱신한다. LLM을 실제 서비스에 올리는 개발자에게 맞는 자격이다.
