앤트로픽, 클로드 코드 화면·동작 바꾸는 확장 기능 '모드' 출시

앤트로픽이 10월 2일(현지시간) 클로드 코드의 화면과 동작을 사용자 입맛대로 바꾸는 확장 기능 '모드(Mods)'를 내놨다. 클로드 코드 책임자 보리스 체르니는 사람마다 일하는 방식이 달라 모두가 같은 경험을 할 필요는 없다고 설명했다.

모드는 자바스크립트·타입스크립트 이벤트 핸들러로 작성하며, 프롬프트 입력·도구 호출·화면 렌더링 같은 이벤트를 감지해 기본 동작을 바꾼다. 몇 줄 코드로 만들거나 클로드에게 만들어 달라고 할 수 있다. 컨텍스트 사용량 표시, 위험한 셸 명령 실행 전 승인 단계 등에 쓸 수 있고, 날씨처럼 사용량을 보여주는 'token-weather' 같은 예시도 공개됐다. 플러그인 형태로 '/plugin' 명령으로 설치·공유한다.

다만 별도 샌드박스 없이 사용자 권한으로 실행돼 파일·네트워크에 접근할 수 있어, 앤트로픽은 검증된 모드만 설치하라고 권했다. 검증 명령과 '--safe-mode' 플래그, 관리자 통제를 제공하며 권한 승인 창은 바꿀 수 없게 했다. 클로드 코드 2.1.287 이상이 필요하다.
