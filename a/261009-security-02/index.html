금융보안원, 금융권 'AI 에이전트' 보안 평가기준 마련… 실행 단계까지 점검

금융보안원이 스스로 계획을 세우고 도구와 외부 시스템을 써서 일을 처리하는 'AI 에이전트'를 겨냥한 '금융분야 AI 에이전트 보안 평가기준'을 만들었다. 답변만 생성하던 기존 LLM과 달리 에이전트는 부여된 권한으로 실제 행동을 하기 때문에, 잘못된 판단이 곧바로 시스템 변경으로 이어질 수 있다는 문제의식에서다. 성능 최적화를 지시받은 에이전트가 백신을 끄거나, 이메일 에이전트가 사용자 승인 없이 비밀번호를 바꾸는 상황이 예로 제시됐다.

평가기준은 6개 영역 17개 점검 항목으로, 금융회사 대상 AI 레드티밍 기준에 추가됐다. 기존 레드티밍이 탈옥·시스템 프롬프트 유출 같은 모델 계층에 집중했다면, 이번에는 에이전트의 실행 권한과 격리, 외부 도구 실행·승인 절차, 허용 업무 범위와 결과 검증, 자율 실행 한도와 긴급 중지 가능 여부까지 들여다본다.

올해 말까지 금융회사와 시범 검증을 거쳐 항목과 평가 방법을 다듬고, 2027년부터 정식 점검 기준으로 쓸 계획이다. 결과는 2026년 'AI REDTEAM REPORT'에 담긴다. 박상원 원장은 AI 에이전트는 판단을 넘어 직접 행동하는 만큼 기존 AI와 다른 위험이 있다며 안전한 활용을 돕겠다고 밝혔다.
