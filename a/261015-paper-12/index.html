실제 개발자는 코딩 에이전트를 벤치마크와 다르게 쓴다… JetBrains 세션 분석

코딩 에이전트 평가는 현실적으로 보이도록 설계되지만, 벤치마크의 상호작용이 사람들의 실제 사용 방식과 같은지는 따져보지 않았다. Igor Slinko 등 연구진은 JetBrains IDE를 쓰는 실제 개발자들의 에이전트 세션 4,782건을 모아 분석했다.

사용자 메시지가 3개 이상인 대화형 세션(전체의 33%)을 보면, 이슈 기반 벤치마크 과제보다 훨씬 다양한 일—코드 관련 질문, 계획, 리뷰, 리팩터링, 코드 실행—이 섞여 있었고 한 세션 안에서도 과제 유형이 바뀌었다. 공개된 상호작용 데이터셋 3종도 세션 길이·과제 유형·전환 패턴('태스크 플로')이 서로 크게 달랐다.

연구진은 기존 벤치마크를 목표 태스크 플로에 맞게 바꾸는 SWE-TaskFlow와 정렬 지표 TFAS를 제안했다. SWE-Bench Pro 700개 과제에 적용한 시범 실험에서 여러 단계로 나눠 풀게 하자 비용은 약 2배가 됐지만 해결률은 일관되게 변하지 않았다.
