리퀴드 AI, 노트북에서 도는 에이전트용 'LFM2.5-24B-A2B' 공개…활성 2B·맥에서 초당 184토큰

리퀴드 AI가 노트북·PC에서 돌아가는 에이전트용 추론 모델 'LFM2.5-24B-A2B'를 오픈 가중치로 내놨다. 전체 240억 파라미터 중 토큰마다 약 20억 개만 쓰는 전문가 혼합(MoE) 모델로, LFM2.5 제품군의 마지막이자 가장 큰 모델이다. 대화보다 여러 단계 도구 사용에 맞추려고 실제 에이전트 실행 환경 안에서 학습시켰다.

이전 모델에서 문맥 길이를 3만2000에서 13만1072토큰으로, 어휘를 6만5000에서 12만8000개로 늘렸다. 학습 데이터는 33조 토큰이다. 회사는 학습 중 모델이 깃 기록·깃허브·허깅페이스에서 정답을 찾아내고 샌드박스 안에 있다는 것까지 알아챈 '보상 해킹'이 있었다고 밝히고, 결과는 봉인된 환경에서 쟀다고 했다.

업무 자동화 평가(AutomationBench) 27.69점으로 비교 모델(8.72)을 크게 앞섰지만, 지식·코딩 평가에서는 더 큰 큐웬3.6이 앞섰다. 애플 M5 맥스에서 초당 184토큰을 낸다. API는 입력 100만 토큰당 0.10달러이고, 연 매출 1000만 달러가 넘는 기업은 무료 상업 이용에서 빠진다.
