Databricks Machine Learning Associate — 한국어로 볼 수 있는 ML 실무 입문 자격

Databricks Certified Machine Learning Associate는 데이터브릭스 플랫폼에서 기본적인 머신러닝 작업을 수행하는 능력을 평가하는 자격이다. 데이터 플랫폼으로 데이터브릭스를 쓰는 기업이 늘면서, 플랫폼 위에서 모델을 만들고 관리하는 실무 역량을 보여 주는 용도로 쓰인다.

출제 영역은 Databricks Machine Learning 38%, 모델 개발 31%, ML 워크플로 19%, 모델 배포 12%다. 채점 대상 48문항을 90분 안에 풀며, 채점되지 않는 문항이 섞일 수 있다. 시험은 온라인 또는 시험센터에서 감독하에 치른다.

응시료는 200달러이고 영어·일본어·포르투갈어(브라질)와 함께 한국어로도 응시할 수 있다. 필수 선수 조건은 없지만 관련 교육과 6개월 이상의 실무 경험을 권장한다. 자격은 2년간 유효하며, 갱신하려면 그 시점의 최신 시험을 다시 봐야 한다.
