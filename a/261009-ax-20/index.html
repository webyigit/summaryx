독파모 3사 AI페스타 부스, 관심은 '성능'에서 '업무 연동·비용'으로

정부 '독자 AI 파운데이션 모델(독파모)' 프로젝트를 향한 관심이 기술 성능에서 실제 업무 활용으로 옮겨가고 있다. 하정우 국가AI전략위원회 부위원장은 8일까지 코엑스에서 열린 'AI페스타 2026'을 둘러본 뒤 "독파모 3개사가 글로벌에서도 인정받는 수준에 도달했다"고 평가했다.

현장 기업 관계자는 예전엔 모델 기본 기능을 주로 묻던 관람객들이 이제는 기존 업무 시스템 연동, 운영 비용, 민감 데이터 처리 방식까지 묻는다고 전했다. ERP·오피스 프로그램 연동 질문도 많았다. SK텔레콤은 'A.X K2'로 그래프·업무 자료를 분석하고 사용자 기준에 따라 문서를 검토하는 기능을, LG AI연구원은 'K-엑사원 2.0'의 문서 이해·추론·코딩과 연말정산 PDF 질의응답을 보여줬다.

업스테이지는 '솔라 프로 4'가 규모가 작아 운영 연산 자원이 적다는 점을 내세우며 API 연동과 사내 서버 설치 방식을 안내했다. 문서를 올리고 계약서 검토 같은 업무를 말로 설명하면 AI가 작업 순서를 짜는 문서 처리 에이전트 제작 기능도 공개했다.
