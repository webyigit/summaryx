'시프트 레프트' 확산에 팹 데이터 폭증…공정 단계 AI 검사가 데이터 관리 난제로

반도체 팹들이 불량·수율 문제를 전기 테스트 단계가 아니라 공정 모듈 안에서 바로 잡아내는 '시프트 레프트(shift left)'로 옮겨 가고 있다. 장비 센서 데이터를 실시간으로 흘려보내고 AI·머신러닝 모델로 이상을 감지하거나 공정 조건을 즉시 고치는 방식이다. 예전에는 수율 이탈이 며칠~몇 달 뒤 전기 테스트에서야 드러났다.

문제는 데이터 양이다. 일부 팹은 한 해 수백 페타바이트를 만들고, 센서 샘플링은 초당 1회에서 수십 밀리초 단위로 빨라졌으며 요약값 대신 원시 트레이스 데이터가 쌓인다. 인텔 파운드리·온투 이노베이션·시놉시스·PDF솔루션즈·지멘스 EDA·램리서치 전문가들은 모듈마다 따로 최적화하면 '데이터는 많은데 맥락이 없는' 상태가 돼 모듈 간 상관 분석이 어려워진다고 지적했다.

해법으로는 장비 공급사의 표준 포맷 데이터 제공, 기판 공정 이력의 표준화된 인계, 실측으로 보정한 물리 기반 디지털 트윈, 여러 팹 데이터를 묶은 '가상 플릿' 운영이 거론됐다. 라피더스·테라팹 같은 신규 팹은 처음부터 통합 데이터 체계를 짤 기회가 있다는 분석이다.
