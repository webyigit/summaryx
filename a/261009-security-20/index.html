LLM 가속 도구 LMCache에 CVSS 9.8 원격 코드 실행 취약점… 패치 없어

vLLM 같은 LLM 서버 속도를 높이는 오픈소스 소프트웨어 LMCache에서 인증 없이 원격 코드 실행이 가능한 취약점(CVE-2026-105192)이 공개됐다. JFrog 보안연구팀 유발 모라브치크가 찾아 10월 7일 공개했으며, 외부에서 접근 가능한 주소로 서버를 띄운 경우 위험도는 10점 만점에 9.8이다. 캐시를 별도 서버로 돌리는 멀티프로세스 모드에 인증이 없어, 조작된 메시지 하나로 명령이 실행될 수 있다.

기본값은 로컬호스트라 외부에서 닿지 않지만, 공식 쿠버네티스 예제 배포는 모든 인터페이스에서 대기하고 공식 컨테이너 이미지는 루트 권한으로 실행된다. 영향 범위는 0.3.9(2025년 10월)부터 최신 안정판 0.5.5까지이며, 0.5.6 후보판과 개발 브랜치도 포함된다.

아직 수정 버전도, LMCache의 보안 공지도 없다. JFrog는 멀티프로세스 서버에 외부 주소를 주지 말고 포트를 로컬이나 신뢰하는 클러스터 네트워크 안에 두라고 권했다. 방화벽은 위험을 줄일 뿐 없애지는 못한다.
