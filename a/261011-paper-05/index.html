SuperNav: 모델은 그대로, '하네스'로 어떤 부탁이든 찾아가는 로봇 내비게이션

서비스 로봇은 처음 가 본 공간에서 사람의 다양한 요청을 처리해야 한다. 기존에는 멀티모달 LLM을 내비게이션 데이터로 미세조정해 이동 행동을 직접 예측하게 했는데, 이러면 성능이 훈련 데이터 범위에 묶인다.

SuperNav는 사전학습된 멀티모달 LLM을 고치지 않고 '에이전트 하네스'로 감싼다. LLM은 요청 해석·장면 이해·판단을 맡고, 실제 이동은 내비게이션 도구가 실행한다. 하네스는 이동 기술, 물리 상호작용 도구, 작업 진행·맥락 관리를 제공하며, 이미지 위에 목적지 점을 찍고 실행 결과를 보고 고치는 '시각 포인트' 방식을 쓴다.

특정 물체 찾기, 여러 물체, 필요(수요)에서 출발하는 과제에서 4개 기준선을 앞섰고, HM3D 범주 단위 평가와 실제 사족보행 로봇 배치도 보고했다.
