앤트로픽, 클로드 코드에 작업 지켜보는 보조 에이전트 플러그인 'You should know' 추가

앤트로픽은 2일 코딩 도구 '클로드 코드'에 내장 플러그인 '알아두어야 할 사항(You should know)'을 추가했다. 별도 보조 에이전트가 클로드의 작업을 지켜보다가, 긴 작업 중 사용자가 꼭 알아야 할 내용을 프롬프트 위에 노트로 요약해 알려 준다.

메인 에이전트는 코드 작성과 파일 수정에 집중하고, 보조 에이전트는 많은 파일 수정이나 중요한 결정처럼 사용자가 놓치기 쉬운 부분을 걸러낸다. 기능은 기본 비활성화 상태이며 '/plugin' 메뉴에서 'cc-plugin-you-should-know@builtin'을 선택해야 켜진다.

개발자 사이에선 긴 세션의 주요 결정이나 아키텍처 변경을 추적해 주는 '제2의 눈'이라는 호평과, 백그라운드 감시에 토큰을 더 쓰는 방식은 비효율적이라는 지적이 엇갈린다. 기사는 감시·검증을 맡는 보조 AI를 두는 에이전트 오케스트레이션 흐름이 본격화하고 있다고 평가했다.
