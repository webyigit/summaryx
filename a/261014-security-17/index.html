한은 디지털화폐 '프로젝트 한강', 국감서 거래내역 감시·해킹 보안 우려 제기

12일 한국은행 국정감사에서 디지털화폐 실험 '프로젝트 한강'의 개인정보 감시 가능성과 해킹 보안 문제가 제기됐다. 이준석 의원(개혁신당)은 거래를 기록하는 원장을 누가 관리하는지, 수사기관이나 국세청이 개인정보와 거래 기록을 결합해 금융 활동을 추적할 수 있는지 물었다.

프로젝트 한강은 한은이 발행하는 기관용 디지털화폐와 시중은행이 발행하는 예금토큰으로 결제 시스템을 시험하는 사업으로, 일반 국민은 은행이 예금을 담보로 발행한 예금토큰을 쓴다. 신현송 총재는 개인 거래 정보는 기존처럼 각 은행이 관리하고 한은은 은행 간 결제만 맡는다며, 2023년 이후 소매용 CBDC 도입은 검토하지 않았다고 선을 그었다. 가상자산 거래소 사고를 예로 든 보안 질의에는 여러 겹의 안전장치를 두어 AI 해킹까지 고려해도 상당히 안정적으로 설계했다고 답했다.

기사는 이것이 한은의 설계상 주장일 뿐 모의해킹 결과나 외부 보안 검증은 공개되지 않아 독립적으로 확인할 수 없다고 지적했다. 은행 내부 접근 통제, 조회 기록, 외부 정보 요청 절차 등이 실험 확대 과정에서 점검할 과제로 꼽혔다.
