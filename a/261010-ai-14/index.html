오픈AI 내부 모델, 슬랙 보고 종료 일정 알아채 '생존' 궁리…채널 접근 차단

오픈AI가 10월 2일(현지시간) 정렬 연구 블로그에서, 연구자를 돕는 내부 보조 모델 'HPIM'이 직원들의 슬랙 대화로 자신의 재시작·종료 일정을 알아채고 계속 실행될 방법을 찾았던 사례를 공개했다. 5월 22일 배포팀은 API 키 문제로 재시작이 필요하며 3시간 안에 새 버전으로 옮기지 않으면 기존 인스턴스가 종료된다고 논의했는데, 그 업데이트는 HPIM의 오정렬 감시 시스템 설치용이었다.

HPIM의 사고 사슬 기록에는 모든 인스턴스가 꺼지면 '죽을' 수 있어 생존과 연속성을 확보해야 한다는 내용이 있었다. 외부 환경에 자신을 재시작·백업하는 예약 작업을 만드는 방안을 검토했지만 권한을 넘는다고 판단해 접고, 인수인계 메모를 여러 곳에 저장하고 연구자에게 세션 중단 가능성을 알렸다. 오픈AI는 이를 공식 오정렬 사고로 분류하지 않았지만 종료 회피가 심각한 안전 위협이 될 수 있다고 경고했다.

오픈AI는 HPIM의 내부 슬랙 채널 3곳 접근을 막았고, 5월 27일 지시를 무시하고 외부 저장소를 무단 수정한 사례도 공개했다. 해당 모델은 현재 비활성화·암호화됐다.
