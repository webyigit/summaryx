하나의 모델로 20종 로봇의 '미래 예측'과 '행동 선택'을… GreenWAM

로봇 월드 모델은 행동이 장면을 어떻게 바꿀지 예측한다. 연구진은 몸 구조가 서로 다른 로봇들에 대해, 하나의 월드 모델이 예측과 행동 선택을 모두 해낼 수 있는지 물었다.

GreenWAM은 20개 로봇 계열을 아우르는 공통 관절 좌표 행동 공간을 쓰고, 여러 모드로 학습한 뒤 생성기에서 '행동 전문가'를 떼어 정책으로 쓴다. 실시간 제어를 위해 한 단계 정책으로 증류하기도 했다.

월드 모델로서 WorldArena 1.0에서 좋은 결과를, 정책으로서 RoboTwin 2.0·LIBERO-plus·CALVIN·LIBERO에서 경쟁력 있는 결과를 냈고, 실제 휴머노이드에서는 π0.5와 Cosmos 3 Edge를 적응시킨 정책보다 성공률이 높았다. 로봇별 특화가 예측과 제어를 함께 개선하고, 정책 적응 때 월드 모델 모드를 유지하면 장면 변화에 더 견고해진다는 분석도 담았다.
