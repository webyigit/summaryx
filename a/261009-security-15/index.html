일본, 모바일 API 악용·메타베이스 공격으로 웹 개인정보 유출 급증

일본 침해사고 대응 기관 JPCERT/CC가 10월 8일 주의보를 내고, 최근 잇따른 일본 기업·기관의 개인정보 유출이 모바일 앱 API 악용과 알려진 소프트웨어 취약점 공격과 관련 있다고 밝혔다. 온라인 쇼핑몰, 회원 서비스, 고객 지원, 도서관 검색, 관광열차 좌석 예약 시스템까지 피해 범위가 넓다. 특히 BI 도구 메타베이스의 CVSS 10.0 SQL 인젝션 취약점이 8월 제로데이로 악용됐다.

보안업체 마크니카 집계로 올해 10월 6일까지 일본에서 웹 시스템을 통한 개인정보 유출이 119건으로, 2025년 84건·2024년 62건을 이미 넘었다. 이 중 81건이 7월 이후에 몰렸다. 같은 기간 다른 13개 국가·지역에서도 비슷한 사례 99건이 있었고 한국이 30건으로 가장 많았다. 주차·카셰어링 업체 파크24는 약 660만 계정 정보와 운전면허증 이미지 약 160만 건이, 야키니쿠킹 운영사는 앱 회원 정보 1,078만여 건이 유출됐다고 밝혔다.

공격 주체는 특정되지 않았다. JPCERT/CC는 요청 횟수 제한, 모든 API 접근 통제, 최소 권한, 짧은 토큰 수명 등을 권고했고, 일본 개인정보보호위원회도 보유 개인정보가 여전히 필요한지 점검하라고 당부했다.
