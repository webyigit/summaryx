웹툰 IP 스튜디오 메타툰, 중기 경영혁신 대상 수상…신진 작가 33명 발굴

글로벌 웹툰 IP 제작 스튜디오 메타툰이 한국경영혁신중소기업협회가 뽑은 '2026 중소기업 경영혁신 대상' 수상 기업 8곳에 들어 중소벤처기업부 장관상을 받는다. 콘텐츠 IP 분야의 혁신성·성장 가능성·시장 경쟁력이 평가됐으며, 시상식과 기업설명회(IR)는 11월 19일 청주 오스코에서 투자 상담 프로그램과 함께 열린다.

메타툰은 앞서 금융위원회 '혁신 프리미어 1000'에도 문체부·한국콘텐츠진흥원 추천으로 이름을 올려 자체 웹툰 IP 기반 사업 확장성을 인정받았다. 작가 발굴에도 힘써 9월 마친 4번째 공모전까지 신진 작가 33명을 발굴했고, 10월 1일부터 5번째 작가 모집 공모전을 진행한다.

IP 확장도 이어진다. 웹툰 '사막에 핀 나의 꽃'의 OST 'Dreamer'(보컬 정인성)는 자체 IP 기반 11번째 공식 OST다. 회사는 음악·굿즈 등으로 수익 구조를 다변화하고 신진 작가 협업을 넓히겠다고 밝혔다.
