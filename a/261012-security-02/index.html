쏘카, 회원 조회 API 허점 노린 공격에 고객 248명 정보 유출…10분 만에 차단

카셰어링 업체 쏘카가 외부 공격자가 내부 회원 조회 API를 악용해 고객 248명의 개인정보가 유출됐다고 공지했다. 공격은 10월 7일 밤 10시 13분 시작됐고 쏘카는 10시 23분 이상 접근을 감지해 공격 IP와 경로를 차단했다.

피해자는 2012년 4월~2013년 4월 가입 고객으로, 이름·생년월일·성별·전화번호·이메일·주소·회원번호와 운전면허 일부 정보(지역 코드·발급 연도)가 포함됐다. 비밀번호와 카드·계좌 등 결제 정보는 빠졌다. 쏘카는 요청자가 해당 고객 정보에 접근할 권한이 있는지 제대로 확인하지 않는 BOLA 취약점이 악용됐다고 설명했다.

8월 무신사 29CM의 API 유출과 비슷한 방식이지만 같은 공격자라는 뜻은 아니라고 기사는 덧붙였다. 쏘카는 10월 8일 KISA와 개인정보보호위원회에 신고했고 피해 고객에게 개별 통지 중이며, 링크나 인증 정보를 요구하는 사칭 연락에 주의하라고 당부했다.
