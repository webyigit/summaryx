메타 첫 프런티어 모델 '뮤즈 원더' 출시…장기 기억·과제 지속에 초점, 오퍼스 5.5와 같은 API 가격

메타가 12일(현지시간) 자체 최고 성능 모델 '뮤즈 원더'와 상위판 '뮤즈 원더 풀'을 공개했다. 알렉산더 왕 최고AI책임자가 이끄는 MSL이 만든 뮤즈 스파크 계열의 대형 버전으로, 오하이오 프로메테우스 데이터센터에서 학습했다. 메타는 14개월 전 AI 개발 조직을 재편한 뒤 이제 기반 구축 단계를 지나 프런티어 경쟁에 들어섰다고 밝혔다.

핵심 기능은 대화 내내 사용자·과제 정보를 기억해 쓰는 '액티브 메모리'와, 작업 중 막히면 다른 길을 찾는 '액티브 포커스'다. 텍스트·이미지·영상·음성을 입력받고 컨텍스트는 100만 토큰이다. 메타 발표 기준 DeepSWE 1.1에서 풀 79.0%, 원더 78.8%로 클로드 오퍼스 5.5(74.2%)·GPT-6 아스트라(74.1%)를 앞섰지만 터미널벤치 4.0에서는 뒤졌다. 아티피셜 애널리시스 지능 지수에서는 풀 56점으로 오퍼스 5.5(58점)에 이어 상위권이다.

원더 API 가격은 입력 100만 토큰당 4달러·출력 20달러로 오퍼스 5.5와 같다. 다만 과제당 평균 비용은 4.52달러로 아스트라(3.26달러)보다 높았고, 풀은 API 없이 월 50·200달러 '뮤즈 코드' 구독자만 쓸 수 있다. 발표 당일 메타 주가는 약 4% 올랐지만, 개인 메시지 접근 우려와 API 제한이 실제 확산의 변수로 꼽힌다.
